# 🎯 SmartLead — AI-Assisted Lead Scoring API

> **Built with FastAPI + SQLAlchemy + AI Coding Assistants (GitHub Copilot / Cursor)**  
> **Demonstrates critical review and improvement of AI-generated code**

---

## 📋 Overview

SmartLead is a production-ready REST API for scoring sales leads using an explainable AI scoring algorithm. It was built primarily using **LLM coding assistants** (GitHub Copilot, Cursor IDE), with **systematic human review and improvement** of the AI-generated code.

This project directly addresses the Salesforce SWE requirement: *"Experience using and critically reviewing code generated by LLM coding assistants and agentic tools."*

---

## 🚀 Features

| Feature | Description |
|---------|-------------|
| **Lead CRUD** | Create, read, update, delete leads with full validation |
| **AI Scoring** | Weighted scoring algorithm (Budget 30%, Timeline 35%, Source 20%, Job Title 15%) |
| **Explainability** | `/score-breakdown` endpoint shows exactly how each score was calculated |
| **Batch Operations** | Import multiple leads in a single request |
| **Filtering & Sorting** | Filter by score, source; sort by any field |
| **Duplicate Prevention** | Unique email constraint prevents duplicate leads |
| **Auto Re-scoring** | Score recalculates automatically on lead update |
| **Health Check** | `/health` endpoint for monitoring |
| **CORS Enabled** | Ready for frontend integration |
| **Comprehensive Tests** | 12+ test cases covering edge cases |

```bash

# Create virtual environment
```

## 📡 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/health` | Health check |
| POST | `/leads` | Create a new lead (auto-scored) |
| GET | `/leads` | List all leads (with filters) |
| GET | `/leads/{id}` | Get a specific lead |
| PUT | `/leads/{id}` | Update a lead (re-scored) |
| DELETE | `/leads/{id}` | Delete a lead |
| GET | `/leads/{id}/score-breakdown` | Explainable score breakdown |
| POST | `/leads/batch` | Batch create leads |

## 🧪 Example Usage

### Create a Lead
```bash
curl -X POST "http://localhost:8000/leads" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "email": "john@example.com",
    "company": "Acme Corp",
    "job_title": "CTO",
    "budget": 50000,
    "timeline": "3_months",
    "source": "referral"
  }'
```

**Response:**
```json
{
  "id": 1,
  "name": "John Doe",
  "email": "john@example.com",
  "company": "Acme Corp",
  "job_title": "CTO",
  "budget": 50000.0,
  "timeline": "3_months",
  "source": "referral",
  "score": 78.5,
  "created_at": "2026-08-06T15:30:00",
  "updated_at": "2026-08-06T15:30:00"
}
```

### Get Score Breakdown (Explainable AI)
```bash
curl "http://localhost:8000/leads/1/score-breakdown"
```

**Response:**
```json
{
  "total_score": 78.5,
  "budget_score": 25.0,
  "timeline_score": 30.0,
  "source_score": 15.0,
  "job_title_score": 8.5
}
```

## 📊 Scoring Algorithm

The lead scoring algorithm uses a **weighted multi-factor model**:

| Factor | Weight | Logic |
|--------|--------|-------|
| **Budget** | 30% | Logarithmic scale — diminishing returns above $100K |
| **Timeline** | 35% | Immediate = 100pts, 3 months = 80pts, 6 months = 50pts, 1 year = 25pts |
| **Source** | 20% | Referral = 100pts, LinkedIn = 85pts, Website = 60pts, Cold = 30pts |
| **Job Title** | 15% | C-level = 100pts, VP = 90pts, Manager = 60pts, Junior = 25pts |

**Why this matters:** The algorithm is **explainable** — every score component is transparent, building trust with users (aligns with Salesforce's "Trust" value).
